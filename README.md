# NOVA 1.4.0 — Personal AI Companion

Your personal AI companion for Android.

## Download

[Download NOVA 1.4.0 APK](https://github.com/sachiii143/nova-apk-download/releases/latest)

## Installation guide

1. Open the download link on your Android phone.
2. Download NOVA-1.4.0.apk.
3. Open the downloaded APK.
4. If Android asks, allow your browser or file manager to install unknown apps.
5. Tap Install.
6. Open NOVA.

## First-time setup

1. Open Settings inside NOVA.
2. Open AI Voice Provider / API Keys & Connection Tests.
3. Select the AI provider you want to use.
4. Enter your own API key:
   - Gemini API key: obtain one from https://aistudio.google.com/apikey
   - DeepSeek API key: obtain one from https://platform.deepseek.com/
5. Select or confirm the model.
6. Save the settings.
7. Run the connection test.
8. Return to the chat screen and test NOVA.

You must obtain and supply your own API key. API usage may incur charges from the provider.

## Permissions

Android may request permissions when you use particular features, such as:
- Microphone for voice interaction.
- Contacts for contact-related actions.
- Accessibility for screen-assistant features.
- Notifications for reminders and updates.

Grant only the permissions you understand and need.
